# ما أحتاجه منك لبناء القصّات الثماني

املئي الجدولين وأرسلي الصور. هذا كل المطلوب.

---

## ١ · الصور — ٢٤ صورة

**٨ قصّات × ٣ أوجه** (أمامي، خلفي، جانبي).

### الشروط

| الشرط | التفصيل |
|---|---|
| **المقاس** | **أقلّ من ٢٠٠٠ بكسل** في الطول والعرض |
| الصيغة | **SVG** أفضل · وإلا **PNG** |
| الرسم | تحديد بالأسود، بلا تظليل ولا ألوان |
| الخلفية | شفّافة أو بيضاء نقيّة |
| القصّ | **على حدود العباية تماماً، بلا هوامش** |

> **مهم جداً — المقاس.** صورة فوق ٢٠٠٠ بكسل تُسقط جلستي بالكامل
> ويضيع الشغل. لو صوّرتِ بالجوال فالصورة عادةً ٣٠٠٠–٤٠٠٠ بكسل،
> فصغّريها قبل الإرسال. أي محرّر صور يسوّي ذلك، أو أرسليها وأنا
> أصغّرها لكن **قولي لي قبل أن أفتحها**.

> **مهم جداً — القصّ.** الصورة مقصوصة على حدود العباية بلا أي فراغ
> حولها، لأن منها أحسب المقياس. لو كان فيها هامش صار قياس النقشة
> خطأً. وأضيف معايرة في اللوحة للتصحيح لو لزم.

### تسمية الملفات

```
1-أمامي.png     1-خلفي.png     1-جانبي.png
2-أمامي.png     2-خلفي.png     2-جانبي.png
...
8-أمامي.png     8-خلفي.png     8-جانبي.png
```

## ٣ · تعريف المقاسات — أكّدي أو صحّحي

هذا أهمّ سؤال، وخطأ واحد هنا يُفسد كل المقاسات. **أمام كل مقاس
افتراضي: اكتبي «صح» أو صحّحيه.**

| المقاس | فهمي | صح / التصحيح |
|---|---|---|
| **الصدر** | العرض **مفروشاً** من طرف إلى طرف عند الإبط (ليس المحيط) |  |
| **الطول** | من أعلى الكتف إلى أسفل الذيل |  |
| **الأكتاف** | من طرف كتف إلى طرف كتف |  |
| **أسفل العباية** | عرض الذيل **مفروشاً** من طرف إلى طرف |  |
| **قطر اليد** | عرض فتحة الأسوَرة **مفروشة** (ليس المحيط) |  |
| **طول اليد** | من طرف الكتف إلى طرف الأسوَرة |  |

> **لماذا أسأل؟** «الصدر ٤٠» تعني شيئين مختلفين: مفروشاً ٤٠ إنش،
> أو محيطاً ٤٠ (أي مفروشاً ٢٠). الفرق **ضعف**، وسيخرج قياس النقشة
> خطأً بمقدار الضعف. وسبق أن وقعتُ في مثله: ربطتُ العرض بأوسع نقطة
> بدل الصدر فانسحقت القصّات الواسعة.

## ٤ · سؤالان أخيران

**أ) «كل قطعة على حدى» — فهمي:**
كل وجه (أمامي/خلفي/جانبي) يكون **سطح عمل مستقلاً**: تختارين الوجه،
فتظهر العباية وحدها بمقاسها، وتضعين النقشة عليه وتقرئين مقاسها
وتطبعينها — ثم تنتقلين لوجه آخر.
