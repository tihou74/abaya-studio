# ارفعي صور القصّات هنا

## الشروط

| | |
|---|---|
| المقاس | **أقلّ من ٢٠٠٠ بكسل** في كل بُعد |
| الصيغة | PNG أو JPG (أو SVG) |
| الرسم | تحديد أسود، خلفية بيضاء |
| القصّ | على حدود العباية بلا هوامش |

> لو لم تكوني متأكّدة من المقاس: **ارفعيها وقولي لي قبل أن أفتحها**
> فأفحصها وأصغّرها. لن تضيع الجلسة.

## التسمية

اسم القصّة بالإنجليزية، ويكفي ملف واحد فيه الوجهان:

```
closh.jpg        ← مثال منفَّذ
<name>.jpg       ← قصّتك الجديدة
```

## والمقاسات

اكتبيها في المحادثة بالإنش، ومعها **محيط أم مفروش** للصدر والذيل
والكُمّ:

| المقاس | الكلوش (مثال) |
|---|---|
| الطول | ٥٨ |
| الصدر | ٢٤ مفروش |
| الأكتاف | ١٥ |
| أسفل العباية | ١٢٠ محيط |
| طول اليد | ٢٤ |
| عرض الكُمّ | ١٢ محيط |
