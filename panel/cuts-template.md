# إضافة قصّة جديدة

كل قصّة **بيانات فقط** — لا شيء في الشيفرة يُعدَّل. القطع (الواجهة
والخلفية والكُمّ والقطعة المفروشة ورسوم المرجع) تُبنى آلياً من الأوجه
التي تُزوِّدينها، ومعامل القياس يُحسب لكل وجه من ارتفاع صورته.

## الخطوات

### ١ · ضعي الصور في `panel/cuts/`

| الوجه | إلزامي؟ | أثره |
|---|---|---|
| **أمامي** | ✅ | مرجع كل المقاسات — بلا الأمامي تُرفض القصّة |
| خلفي | اختياري | قطعة «Sketch · back» |
| **جانبي** | اختياري | **يُشغّل منصّة الدوران** (لا توجد لأي قصّة بعد) |

شرطان:

1. **مقصوصة على حدود العباية بلا هامش** — ارتفاع الصورة يُعتبر هو
   الطول الحقيقي. وإن لم يكن القصّ مضبوطاً فلا تُعدّلي الأرقام:
   استعملي **المعايرة** في اللوحة.
2. **لا يتجاوز أيّ بُعد ٢٠٠٠ بكسل.**

```bash
python3 check_png.py panel/cuts          # يفحص ويطبع الأبعاد
python3 check_png.py --fix panel/cuts    # يُصغّر المتجاوز
```

### ٢ · أضيفي الكتلة إلى `panel/cuts-data.js`

انسخيها بعد فاصلة في نهاية المصفوفة:

```js
  ,{
    id: "my-cut",                      // لاتيني بلا مسافات
    name: "اسم القصّة",
    measures: {
      length: 58,        // الكتف إلى الأسفل — مرجع كل المقاسات
      chest: 24,
      shoulder: 15,
      hem: 120,
      sleeveLength: 24,
      sleeveWidth: 12
    },
    circ: { chest: false, hem: true, sleeve: true },
    faces: {
      front: { src: "cuts/my-cut-front.png", w: 403, h: 1026 },
      back:  { src: "cuts/my-cut-back.png",  w: 412, h: 1018 },
      side:  { src: "cuts/my-cut-side.png",  w: 300, h: 1020 }
    }
  }
```

`w` و`h` هما أبعاد الصورة بالبكسل — يطبعهما `check_png.py`.

### ٣ · أعيدي البناء

```bash
python3 build_panel.py
```

## أهمّ نقطة: **محيط أم مفروش؟**

لكل من الصدر والذيل والكُمّ. الفرق **ضعف** ويقلب كل القياسات:

| القصّة | الصدر | الذيل | الكُمّ |
|---|---|---|---|
| الكلوش | مفروش | **محيط** | **محيط** |
| الثوب | مفروش | **محيط** | مفروش |

القصّتان اختلفتا في عُرف الكُمّ — فلا يُفترض شيء.

والبرنامج يحرس التناقض: **صدر مفروش أنحف من الأكتاف مستحيل هندسياً**
(وقع فعلاً في الكلوش: قيل إن الصدر ٢٤ محيطاً، أي ١٢ مفروشاً، والأكتاف
١٥). ويظهر التنبيه في اللوحة، والمفاتيح قابلة للتبديل بضغطة فتُصحَّح
بلا تعديل ملفّ.

## ما يحدث إن كانت القصّة ناقصة

تُستبعد من القائمة **ويظهر سبب واضح** أعلى لوحة القصّات — لا انكسار
صامت. الأسباب المرصودة: مقاس ناقص أو غير موجب، وجه أمامي مفقود، صورة
بلا أبعاد، صورة فوق ٢٠٠٠ بكسل، معرّف فيه مسافات.

## المعايرة

تظهر على رسوم المرجع (`Sketch · …`) لأنها وحدها تُشتقّ من بكسلات
الصورة. اسحبي خطّاً على بُعد تعرفينه (طرف، كُمّ) واكتبي مقداره
الحقيقي بالإنش — فيُصحَّح معامل **ذلك الوجه** وحده، ويُحفظ.

> الرياضيات: إن قاس البرنامج `M` إنشاً وكان حقيقةً `R`، فمعامل
> المعايرة يُضرب في `M/R`، لأن `ppi = (h/length)·calib` ومنه
> `hIn = length/calib`.
